### 数据口径

- 财务采用 2021–2025 五个完整年度；CAGR 使用四个增长区间，是报告美元口径，包含并购、业务范围和汇率影响。
- 管线及公司研发投资框架为 2026-07-27 官方快照。“Under review”指一个或多个主要市场，不等于每项资产均已提交美国 NDA / BLA。
- 专利日期与实际仿制进入时间分开；全球产品收入不等于美国收入风险额；未据此预测净收入缺口。
- BD 截至 2026-10-21。30 笔为有来源的编码清单，**不是 AZ 所有 BD 的全量统计**；2026 YTD 不与完整年度直接比较。
- 每页页脚、演讲者备注及 Excel 包含来源与定义。
