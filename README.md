### 如何下载

1. 登录有权访问此仓库的 GitHub 账号。
2. 点击上面的“下载 AstraZeneca PPTX”；或打开 `deliverables` 文件夹，点击 PPTX 文件。
3. 在文件页面点击 **Download raw file**（向下箭头），或 GitHub 显示的 **Download** 按钮。PPTX 无法在线预览时，仍可下载。
4. 如果浏览器询问保存位置，保存到电脑后使用 PowerPoint 打开。

也可以在仓库主页点击绿色 **Code** → **Download ZIP**，解压后在 `deliverables` 中找到 PPTX。
